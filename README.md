# 江苏师大实验室课程助手

适配江苏师范大学实验室安全教育系统的独立用户脚本：可选视频倍速、自动切换下一节、言溪题库查询及官方 AI 回答、试卷逐题作答。

**当前版本：v1.5.1 · Chrome + ScriptCat · 无运行时依赖**

[安装用户脚本](https://raw.githubusercontent.com/haycel07/jsnu-course-assistant/main/jsnu-course-assistant.user.js) · [开发说明](docs/DEVELOPMENT.md) · [更新记录](CHANGELOG.md)

## 功能

| 功能 | 说明 |
|---|---|
| 可选倍速 | 1、1.25、1.5、2、3、4、5、8、10 倍，记住选择；初次默认 10 倍 |
| 自动下一节 | 视频自然结束后，通过页面原有课程切换逻辑进入下一节 |
| 视频习题 | 识别文字单选、多选、判断题，查询并选择答案 |
| 多选处理 | 每次勾选一项，等待页面更新，全部选项核对后再提交 |
| 官方 AI 备用查询 | 题库题干不匹配或无答案时，追加一次言溪官方 AI 查询 |
| 试卷导航 | 当前题完成后点击“下一题”；末题核对题号和未答标记后提交、确认 |
| 统一面板 | 左上角显示倍速、视频与答题状态，支持收起、暂停和重试 |
| Token 管理 | 保存后清空并隐藏输入区；可通过“管理令牌”重新打开 |

## 支持页面

仅匹配 `lsoetp.jsnu.edu.cn`，实际功能限制在以下路径：

- `/students/courseDetail`：课程视频、视频习题、自动下一节。
- `/students/questionList`：已经打开的试卷，逐题处理及末题提交。

脚本不会自动点击考试入口，也不会签署承诺书。其他学校、图片题、多媒体题及填空题未做适配。

## 安装

1. 在 Chrome 安装 **ScriptCat** 用户脚本管理器。
2. 打开上方“安装用户脚本”链接，根据 ScriptCat 提示安装；也可以新建脚本，将 `jsnu-course-assistant.user.js` 全文粘贴后保存。
3. 打开目标网站，刷新课程或试卷页面。
4. 确认左上角出现“江苏师大课程助手 v1.5.1”。

### 从旧版本升级

在原有合并脚本或原题库脚本内覆盖源码，保存后刷新，以保留该脚本的 Token 存储。停用旧的独立视频脚本和其他重复副本，仅启用一份当前脚本。

## 配置言溪题库与 AI

1. 在 [言溪个人中心](https://tk.enncy.cn/user/dashboard) 获取自己的 Token。
2. 在脚本面板输入 Token，点击“保存令牌”。输入区会自动隐藏。
3. 启用账户的 AI 搜题，并将“搜索模式”设为 **强制AI（仅用AI搜索）**，用于普通题库不匹配后的 AI 查询。
4. 返回学校页面，保持页面可见，开始播放或打开待处理试卷。

Token 使用 ScriptCat 的 GM 存储，代码中没有预置密钥。不要把 Token 放进 Issue、截图或 Git 提交。

“强制 AI”是言溪账户级设置，也会影响其他使用同一 Token 且未限制本地查询的程序；AI 查询消耗言溪账户的积分/次数，具体规则见[官方说明](https://tk.enncy.cn/tk/article?uid=e61bfd404b96483baba0712937b507ec)。

### 查询流程

```text
读取当前题干与选项
    ↓
言溪本地题库查询
    ├─ 题干匹配 → 映射答案
    └─ 不匹配 / 无答案 → 言溪官方 AI → 检查 AI 标记 → 映射答案
    ↓
逐项选择 → 核对完整选中集合
    ├─ 视频习题：提交，由网站继续播放
    └─ 试卷：下一题；末题核对后提交并确认
```

初次请求带 `__local_only__: true`，备用请求为 `false`。该参数来自官方网页客户端；其在 POST v2 请求中的服务端分流行为尚未独立验证。备用结果必须包含 `data.ai === true`，否则脚本提示配置问题，不会将普通题库结果冒充 AI 答案。

## 使用面板

- **播放速度**：即时选择，刷新或换节后保留。
- **暂停自动切换**：只暂停换课，倍速仍由下拉框控制。
- **暂停答题**：暂停查题和自动提交，取消当前请求。
- **重试本题**：清除当前题缓存后重新尝试。
- **管理令牌**：展开输入区，可更新或清除 Token。
- **收起 / 展开**：折叠整个面板内容。

页面在后台时不会自动填答或导航。查询期间手动更改答案、题目变化、选项冲突或接口失败时，脚本会显示状态并停止当前动作；AI 超时上限为 120 秒，不会无限重试。

## 常见问题

**提示“未取得官方 AI 结果”**

检查言溪账户是否已开启 AI、是否为强制 AI 模式、积分是否可用。新版只接受明确标记为 AI 的备用响应。

**显示找不到提交按钮**

确认安装的是最新版。Ant Design 会把按钮渲染为“提 交”，脚本已经兼容空白。

**多选没有全部勾上**

先确认只启用一份脚本。当前版本逐项等待页面状态更新；若最终选中集合与答案不符，会停止提交并在面板提示。

**提示“答案无法唯一映射到当前选项”**

更新至 v1.5.1 或以上。旧版可能把 `#` 分隔答案中，选项全文内部的顿号或分号误拆成额外答案；当前版本优先按结构分隔符解析并保留选项内部标点。若更新后仍出现，请提供脱敏后的原始答案格式。

**最后一题没有交卷**

检查题号、总题数与网站的已答标记。仍有未答标记、按钮状态不一致或答案未能映射时，不会自动交卷。

**更新后还是旧面板**

保存脚本后刷新目标页面；当前页面中的旧实例不会因为编辑器保存而自动替换。
